# projectbrief.md

## Core Purpose
An appointment booking system (Makabasla) built with a scalable, modern microservices architecture to handle scheduling, payments, and client management.

## Goals
- Multi-service architecture for independent scalability.
- Robust authentication and authorization using industry standards.
- High availability via service discovery and health monitoring.
- Seamless transition from legacy Spring Boot to high-performance Go-based services.
