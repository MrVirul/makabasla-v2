# productContext.md

## Problem Statement
Small businesses needing an integrated solution for booking appointments, managing tasks, and handling billing without monolithic overhead.

## User Personas
- **Customers**: Book appointments via the webstore or direct booking link.
- **Admin/Staff**: Manage schedules, track tasks, and handle billing/IAM via a secure dashboard.

## Key Workflows
1. **Appointment Booking**: Service-based time-slot selection and confirmation.
2. **Identity Management**: Granular control via Keycloak-integrated IAM service.
3. **Billing**: Automated invoice generation based on completed appointments.
